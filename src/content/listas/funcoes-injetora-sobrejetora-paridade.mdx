1. **(ENEM – adaptado)** Seja <i>f</i> : ℝ → ℝ definida por <i>f</i>(<i>x</i>) = 3<i>x</i> − 5. Qual das afirmações abaixo é **verdadeira**?

   1. <i>f</i> é sobrejetora, pois para todo <i>y</i> ∈ ℝ existe <i>x</i> ∈ ℝ tal que <i>f</i>(<i>x</i>) = <i>y</i>.
   1. <i>f</i> é sobrejetora, mas não é injetora, pois <i>f</i>(1) = <i>f</i>(−1).
   1. <i>f</i> é injetora, mas não é sobrejetora, pois o contradomínio é maior que a imagem.
   1. <i>f</i> não é injetora, pois existem dois valores distintos de <i>x</i> que produzem o mesmo <i>f</i>(<i>x</i>).
   1. <i>f</i> não é nem injetora nem sobrejetora.

1. Considere a função <i>f</i> : ℝ → ℝ definida por <i>f</i>(<i>x</i>) = <i>x</i><sup>2</sup>.

   1. Calcule <i>f</i>(2) e <i>f</i>(−2). O que você conclui sobre a injetividade de <i>f</i>?
   1. A função <i>f</i> é sobrejetora? Justifique sua resposta indicando se existe <i>x</i> ∈ ℝ tal que <i>f</i>(<i>x</i>) = −4.
   1. Restrinja o domínio para <i>f</i> : [0, +∞) → [0, +∞). Agora <i>f</i> é bijetora? Explique.

1. Dada a função <i>f</i> : <i>A</i> → <i>B</i> com <i>A</i> = \{1, 2, 3, 4\}, <i>B</i> = \{2, 4, 6, 8\} e lei <i>f</i>(<i>x</i>) = 2<i>x</i>.

   1. Liste todos os pares (<i>x</i>, <i>f</i>(<i>x</i>)) da função.
   1. Verifique, pela definição, se <i>f</i> é injetora.
   1. Verifique se <i>f</i> é sobrejetora comparando a imagem de <i>f</i> com o contradomínio <i>B</i>.
   1. Conclua se <i>f</i> é bijetora.

1. Uma função <i>f</i> : <i>A</i> → <i>B</i> é **bijetora** quando é, simultaneamente, injetora e sobrejetora. Assinale a alternativa que apresenta uma condição **necessária** para que uma função <i>f</i> : <i>A</i> → <i>B</i> seja bijetora.

   1. <i>A</i> e <i>B</i> devem ser conjuntos infinitos.
   1. Todo elemento de <i>B</i> deve ser imagem de *exatamente um* elemento de <i>A</i>.
   1. Deve existir pelo menos um elemento de <i>B</i> que não é imagem de nenhum elemento de <i>A</i>.
   1. A lei de formação deve ser polinomial.
   1. Os conjuntos <i>A</i> e <i>B</i> devem ser iguais.

1. Uma função <i>f</i> de domínio simétrico em relação à origem é chamada de:

   - **par**, se <i>f</i>(−<i>x</i>) = <i>f</i>(<i>x</i>) para todo <i>x</i> do domínio;
   - **ímpar**, se <i>f</i>(−<i>x</i>) = −<i>f</i>(<i>x</i>) para todo <i>x</i> do domínio.
